Accueil Conditions d’utilisation Politique de confidentialité

1. Données traitées

Creator OS peut traiter l’identifiant du compte TikTok, le nom d’affichage, l’avatar, les autorisations accordées, les jetons OAuth, les chemins locaux des vidéos, leurs empreintes SHA-256, les métadonnées de publication et les statuts de traitement.

2. Finalités

Ces données sont utilisées uniquement pour connecter le compte autorisé, éviter les doublons, envoyer les contenus demandés, suivre leur traitement et afficher leur état à l’utilisateur.

3. Stockage

Les jetons et données techniques sont stockés localement sur l’ordinateur de l’utilisateur, notamment dans le Trousseau macOS et dans des bases SQLite locales. Creator OS ne vend pas les données personnelles.

4. Transmission

Les données nécessaires sont transmises à TikTok uniquement lorsque l’utilisateur demande une connexion ou un envoi. Les échanges utilisent les API officielles de TikTok.

5. Conservation et suppression

Les données locales sont conservées tant que le compte reste connecté ou que les historiques sont nécessaires au fonctionnement. L’utilisateur peut révoquer l’accès depuis TikTok et demander la suppression des données locales associées.

6. Droits et contact

Pour demander l’accès, la rectification ou la suppression des données associées à Creator OS, contactez SuccessFuel via le compte officiel @successfuelfr.

7. Mise à jour

Cette politique peut être mise à jour pour refléter les évolutions techniques ou réglementaires. La date de la dernière version est indiquée en haut de cette page.
